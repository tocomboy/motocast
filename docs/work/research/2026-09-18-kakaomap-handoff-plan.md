# 카카오맵 경로 실행 — 디자인과 구현 계획

- 결정일: 2026-09-18 (Asia/Seoul).
- 작업: [Issue #59](https://github.com/tocomboy/motocast/issues/59). 정본: [ROUTE-008](../../product/MOTOCAST_SOT.md#route-008--execute-the-summarized-course-in-kakaomap).
- 기준: clean develop `af5c19113bd3e0c6dd104a9cb0bdf0abfcc4f888`, package version `0.3.0`. 원격 develop/main fetch 완료. 이 문서는 현재 서비스 동작이 아닌 확정된 다음 개발 계약이다.
- 이번 승인: Figma 디자인·프로토타입, Git/Issue와 문서 정리. 앱 코드·DB·인증·환경·CI/CD 설정·Preview/Production 배포는 이번 범위에 없다. 문서 준비는 버전 중립이며 구현 릴리스는 `0.4.0` 후보로 별도 확정한다.

## 1. 결정과 변경 이력

2026-09-16 계획의 경유지 5개 제한, 사용자 직접 축소, 순서 보존과 외부 도로 옵션 안내를 유지한다. 2026-09-18 사용자 결정으로 **편집 화면의 `카카오맵으로 열기` 대신 요약 화면의 `경로 실행`**, **모바일 웹 대체 대신 앱 설치 후 재실행**으로 바꾼다. 이전 이슈 문구와 계획은 이 결정으로 대체된다.

현재 앱의 소유자 요약 뒤로가기와 `경로 수정`은 모두 `navigate("editor")`를 호출한다. Figma 모바일의 `경로·시간 수정`과 PC의 `경로 수정`을 `경로 실행`으로 교체한다. 소유자 뒤로가기는 입력을 보존하는 편집 진입으로 유지하고 PC 시안에도 명시한다. 별도 수정 페이지를 만들지 않는다.

같은 날 후속 결정으로 **공유받은 요약에서도 저장·새 일정 생성 없이 직접 실행**하도록 확정했다. 이는 기존 “자신의 새 계획 계산 후에만 공유본 실행” 조건을 대체한다. [준비 PR #67](https://github.com/tocomboy/motocast/pull/67)의 OPEN 상태와 head `b2d1c761707ffb2ebc7f3ca9bb92d6a3adc00569`, CI success를 확인하고 같은 PR을 갱신한다. 앱 구현·병합·배포는 이번 범위에 없다.

| 공유 요약 동작 | 역할 | 배치 |
| --- | --- | --- |
| 경로 실행 | 공유된 출발지·모든 경유지·목적지를 방문 순서대로 카카오맵에 전달. 저장·새 일정·재계산 없음 | 주요 버튼 |
| 새 일정으로 출발 | 공유 코스를 가져와 내 출발 날짜·시간 설정 후 경로·날씨 재계산. 자동 저장 없음 | 보조 버튼 |
| 내 경로로 저장 | 나중에 쓸 코스를 내 컬렉션에 저장. 날짜·시간·과거 결과 제외 | 보조 버튼 |
| 홈으로 | 홈 화면 이동. 새 일정 준비와 무관 | 명시적 상단 탐색 |

## 2. 화면과 사용자 흐름

### 소유자 요약 — 최신 계산 결과

1. 실제 계산 결과가 표시된 라이딩 요약에서 `경로 실행`을 누른다.
2. 경유지가 6개 이상이면 `현재 경유지 {n}개 - 경유지 5개 제한 초과`와 `경유지를 5개 이하로 줄인 뒤 다시 시도해 주세요.`를 표시한다. 외부 이동은 0회이며 `경로 편집으로`와 취소를 제공한다.
3. 경로·출발 시간이 결과 계산 이후 바뀌었으면 `경로를 다시 계산해 주세요`를 표시한다. 예전 결과, 미계산·예시 결과, 미선택·잘못된 좌표도 거부한다.
4. 유효하면 아래 안전 안내를 표시한다. 확인 시 최신 입력과 표시 결과의 일치를 다시 검사한다.
5. PC는 새 탭, 모바일은 카카오맵 앱으로 이동한다. 카카오맵에서 사용자가 경로 옵션과 방문 순서를 확인하고 길안내를 시작한다.
6. 앱이 열리지 않으면 설치 안내로 이동한다. 공식 스토어에서 설치한 후 MOTOCAST로 돌아와 `다시 실행`을 누른다. 재검사와 안전 안내를 거치며 자동 실행하지 않는다.

### 공유 요약 — 공유 장소 직접 실행

1. 정상 해석되어 현재 표시 중인 공유 요약에서 주요 버튼 `경로 실행`을 누른다. 공개 요약을 이미 읽을 수 있다면 직접 실행에 별도 로그인·컬렉션 저장·비공개 코스 조회·새 일정 생성은 요구하지 않는다. 저장/새 일정의 기존 회원 권한은 유지한다.
2. 출발·목적지를 제외한 모든 방문을 세며 식사·휴식·동일 장소 반복도 각각 포함한다. 5개 초과면 `현재 경유지 {n}개 - 경유지 5개 제한 초과`를 표시하고 실행을 막는다. `‘새 일정으로 출발’에서 경유지를 직접 5개 이하로 줄이고 다시 계산해 주세요.`와 `새 일정으로 출발`/`취소`를 제공한다. 원본 공유 경로는 불변이고 임의 삭제·순서 변경·자동 분할은 하지 않는다.
3. 공유 당시 시간·날씨는 현재 주행 기준이 아님을 요약과 확인 안내에 표시한다. 과거 날짜·만료된 날씨만으로 직접 장소 전달을 소유자의 “미계산” 상태로 취급하지 않는다. 공유 계산 결과·ETA·예보를 현재 결과로 승격하거나 현재 날씨라고 보장하지 않는다.
4. 아래 공유본 안전 안내를 확인한 후 장소·좌표·방문 개수와 순서, 현재 표시된 공유본의 동일성을 다시 검사한다. 미해석/실패/알려진 철회 상태, 토큰 교체·화면 이탈·늦은 응답, 누락 장소나 불명확한 순서는 실행을 막는다. 미선택 장소를 추측하거나 지도 표시용 목록을 임의로 합치지 않는다.
5. PC 웹 새 탭 또는 모바일 앱으로 전달한다. 설치/재시도/취소는 같은 공유본 문맥을 유지하며 소유자 요약으로 이동하지 않는다. 확인을 취소하면 공유 요약의 실행 버튼으로 포커스를 돌린다.

### 안전 안내 — 확정 문구

제목: **카카오맵에서 경로 옵션을 확인해 주세요**

오토바이 주행 전 **‘자동차전용도로 제외’** 경로를 선택해 주세요.

카카오맵에는 경유지를 최대 5개까지 전달할 수 있습니다.

카카오맵에서 계산한 경로와 도착 시간은 MOTOCAST와 다를 수 있습니다.

주요 동작: `확인하고 카카오맵 열기`, `취소`. 모바일에는 `카카오맵 설치 안내`도 제공한다. 외부 설정의 적용·확인 완료를 주장하지 않는다.

공유본은 동일한 제목·도로 옵션·5개 제한 안내를 사용하되 첫 문단에 `공유 당시 시간·날씨는 현재 주행 기준이 아닙니다. 장소와 방문 순서만 전달합니다.`를 추가하고 마지막 문단은 `카카오맵에서 계산한 경로와 도착 시간은 공유 요약과 다를 수 있습니다.`로 표시한다. 요약에는 `공유 당시 시간·날씨이며 현재 주행 기준이 아니에요. 경로 실행은 장소와 방문 순서만 전달해요.`를 표시한다.

### 설치·실행 실패와 복귀

- 제목: `카카오맵 앱이 필요합니다`.
- 본문: `카카오맵이 열리지 않으면 앱을 설치한 뒤 MOTOCAST로 돌아와 다시 실행해 주세요.`
- 동작: `카카오맵 설치`, `다시 실행`, `취소`. 실제 앱은 확인 가능한 플랫폼의 공식 스토어로 연결하고, 플랫폼이 불명확할 때 Android/iPhone 선택지를 제공한다. Figma 검수 화면에는 양쪽을 함께 보여 준다.
- 모바일 브라우저의 타이머·visibility 변화로 미설치/실행 성공/길안내 시작을 확정하지 않는다. 설치 도움은 항상 접근 가능하고 웹 길찾기로 대체하지 않는다. 설치 성공 뒤 자동 복귀도 가정하지 않는다.
- 스토어를 다녀올 때 선택 경로와 방문 순서를 유지한다. 브라우저가 페이지를 폐기·재시작하는 경우도 검증한다. 현재 메모리 상태만으로 복구를 보장할 수 없으므로 구현 단계에서 기존 소유자 계획 복구 경로를 먼저 확인한다. 기존 공개 공유 스냅샷에 검증 토큰을 추가하거나 비공개 토큰을 URL/로그/localStorage에 새로 저장하는 방식은 사용하지 않는다. 복구 불가 상태에서는 명시적으로 재준비를 안내하며 오래된 경로를 실행하지 않는다.
- PC 팝업 차단 시 요약을 유지하고 수동 재실행을 제공한다. 열린 탭을 실행 성공으로 단정하거나 무한 재시도하지 않는다.
- 공유본도 설치 후 같은 공유 요약으로 돌아와 재검사·명시적 재실행한다. 메모리 유지와 페이지 폐기/재시작은 별도 검증한다. 복구 불가 시 공유 링크를 다시 열도록 안내하고, 공유 토큰을 외부 URL·로그·새 localStorage에 저장하거나 자신의 코스로 자동 저장하지 않는다.

## 3. 데이터·책임 경계

- 출발·최종 복귀를 제외하고 일반 경유/점심/저녁/휴식/동일 장소 반복을 모두 센다. 순서와 각 방문을 보존한다. 자동 삭제·앞 5개 전달·중복 제거·자동 분할 없음. 내부 `waypointLimits` 변경 없음.
- 외부로는 장소와 방문 순서만 전달한다. 도로 경로선·체류시간·날씨·ETA는 이식하지 않는다. 내부 경로 안전 정책과 시간 계산은 유지한다.
- URL은 공식 host/scheme와 허용된 필드로만 생성한다. 이름 예약문자 인코딩, 유한한 국내 좌표, 위도→경도 순서를 확인한다. `verificationToken`, 세션/공유 토큰, 객체 전체 직렬화 금지.
- 단순 외부 이동에는 검색·경로·날씨 API, 경로 저장·공유 발행을 추가하지 않는다. 별도 SDK·API key·유료 서비스·DB migration은 기본 범위에 없다.
- 소유자: `places.origin`, `places.destination`, 순서가 있는 `EditableWaypoint[]`, `currentCourse`, `liveRoute`/`liveResultStale`와 입력 변경 세대를 사용해 표시 결과와 전달 대상을 결속한다. 코드 조사 위치: `components/planner-dashboard.tsx`, `lib/planner/ordered-waypoints.ts`, `lib/planner/input.ts`.
- 공유본: `components/public-shared-ride.tsx`, `components/shared-ride-snapshot.tsx`, `lib/sharing/contracts.ts`의 공개 `SharedRideSnapshot`은 이미 장소명·좌표와 경로 방문 정보를 포함한다. 직접 실행은 검증된 공개 snapshot에서 최소 장소 목록만 투영한다. 비공개 복사/계획용 `verificationToken`을 가져오거나 회원 전용 API를 호출할 이유가 없다. 공유 토큰·내부 ID·소유자 정보·전체 snapshot·과거 일정/예보를 URL에 넣지 않는다.
- 현재 schemaVersion 3의 방문 목록은 순서·반복·필수 방문 완전성을 검증한다. 구버전에는 미통과 경유지가 있을 수 있으므로 `buildSharedMapPoints`의 표시용 추가 목록을 실행 입력으로 재사용하지 않는다. 구버전에서도 전체 방문 순서를 입증할 수 있을 때만 실행하고, 누락·모호함이 있으면 재준비 안내로 차단한다. 순서를 추정하거나 누락점을 끝에 붙이지 않는다. 이는 구현 전 선행 검증 항목이며 현재 parser만으로 새 직접 실행이 검증됐다는 뜻이 아니다.
- 제안 구조: `lib/planner/kakaomap-handoff.ts`는 최소 장소 입력 검사와 URL 생성, 소유자/공유본별 입력 어댑터는 각각 최신 결과 결속/공유 snapshot 동일성을 소유한다. `components/kakaomap-handoff.tsx`는 확인·취소·재시도·플랫폼 이동을 소유하며 `owner`/`shared` 문맥에 맞는 안내와 복귀를 받는다. 하나의 freshness 검사로 두 계약을 혼합하지 않는다. 명칭은 구현 시 응집도를 기준으로 조정할 수 있다.
- 사용자 확인 이벤트 안에서 재검사와 실행을 수행한다. 중복 탭, 팝업 도중 편집·초기화·계정/화면 변경, 늦은 응답은 오래된 외부 실행을 만들지 못한다. 취소/Escape는 이동 없이 실행 버튼으로 포커스를 돌린다.

소유자의 공유/저장 팝업 배경과 날씨 없음 화면에 복제된 요약 버튼도 수정한다. 소유자 뒤로가기와 기존 공유·저장 동작을 보존한다. 검수 진입 화면은 디자인 검토 도구이며 제품 메뉴가 아니다. Figma의 확인 버튼은 외부 전환 후 안내 시안으로 이동한다. 실제 카카오맵 실행이나 위치 추적을 모사해 성공을 주장하지 않는다. 초과/재계산은 검수 화면으로 접근하는 명시적 상태 시안이며 실제 입력에 따른 동적 검증 증거가 아니다.

공유 요약의 모바일 상단 화살표는 실제로 편집 화면에 연결되어 있던 것을 `홈으로` → 홈 `20:311`로 수정했다. PC `홈으로` → `31:778`도 명시한다. 모바일은 전체 너비의 주요 실행 버튼 아래에 보조 두 버튼, PC는 제목 행 우측에 주요 실행 버튼과 보조 두 버튼을 배치한다. 기존 저장 팝업 내용·저장 반응과 새 일정의 날짜·시간 초기화 반응을 보존한다. 저장 팝업은 공유 요약 배경의 전용 시안으로 연결하고 취소/닫기는 공유 요약으로 복귀한다. 공유 실행의 취소/재시도도 전용 공유 상태로 연결한다.

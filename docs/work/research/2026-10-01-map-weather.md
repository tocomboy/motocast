## 지도 동작과 디자인 대응

기존 Figma `wVNriNWb1OlF21DVq8rqlJ`의 장소 선택 2:162 / 검색 결과 2:163을 조사한 뒤, 아래 사용자 보정에 따라 새 확인 팝업을 먼저 디자인했다. 길게 누름 → 팝업에서 서버 주소 확인 → 명시적 `경유지로 추가` → 일반 경유지 추가 순서다. 취소/응답 지연/오류에서는 경유지를 추가하지 않는다. 키보드 사용자는 지도 중심 선택 버튼을 사용한다. 방문 순서와 20개 경유지 한도, 재계산/공유 승인 무효화는 기존 계약을 유지한다. 공유받은 지도는 이동·확대만 지원한다.

`POST search-places`의 추가 모드 `{mode:"coordinate",latitude,longitude}`는 한국 범위의 유한 좌표와 정확 필드만 허용한다. 기존 회원 확인 후 기존 Local 무료 예산 1회를 확보하고 Kakao coord2address를 한 번 호출한다. 주소가 없으면 빈 결과, 공급자 형식 오류면 실패다. 원래 선택 좌표를 소수점7자리로 고정하고 기존 HMAC 장소 서명을 발급한다. 키워드 검색은 기존 계약 그대로다. 로컬/합성 검사는 실제 Kakao 성공의 대체가 아니다.

## 공식 계약 및 지침 대조

2026-10-01 [Kakao Local 좌표→주소](https://developers.kakao.com/docs/ko/local/dev-guide#coord-to-address)의 WGS84 x/y, 주소 0/1개, 산번지 필드와 [지도 투영 좌표](https://apis.map.kakao.com/web/documentation/#MapProjection_coordsFromContainerPoint), [길찾기 결과 코드](https://developers.kakaomobility.com/affiliate/navi-api/reference)의 101–107 의미를 직접 대조했다. 공급자 원문을 UI에 반영하지 않고 일곱 고정 코드만 전달한다.

디자인 선행 규칙은 사용자가 제공한 현재 AGENTS 및 기존 로컬 정본의 2026-09-22 결정을 원격 후보에 동기화한다. 기존 root dirty 파일은 수정하지 않았고 상세 문서는 동일 바이트로 보존했다. [OpenAI 공식 AGENTS 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md#layer-project-instructions)를 OpenAI Docs로 직접 읽어 저장소 지침이 전역 지침을 상속하는 방식과 대조했다. Figma 선행 자체는 사용자 프로젝트 결정이며 공식 모델 의무가 아니다. 전역 설정·모델·권한 변경은 없고, 디자인6상태를 먼저 렌더한 후 팝업 구현/비교한 이번 실행만 입증한다. 동기화 범위의 최종 대조 PASS이며 모든 미래 작업의 준수를 보장하는 주장으로 확대하지 않는다.

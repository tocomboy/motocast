# KMA 요청 시각 교정 — 근거 기준 결정

2026-09-05. 상태: **APPROVED — 근거 기준 변경 승인, 제품 후보 구현 대기**. 사용자는 정확 일치 유지·제한 실측 기반 요청 선택 평가·채택 질문에 “해”라고 지시했다. [공개 격자 실측](2026-09-05-kma-fixed-grid-observation.md)과 [추가 공식 조사](2026-09-05-kma-ultra-hour-identity.md)를 토대로 진행하며 외부 문의는 하지 않는다.

## 결정 당시의 근거

이전 WEATHER-002와 진행 차단 기록은 요청 선택을 변경하기 전에 공급자의 공식 규칙을 확보하도록 요구했다. typ02 초단기 API가 요청 19:30에 19:00, 요청 18:30에 18:00을 반환했다는 실측은 있었지만, 이를 설명하는 공식 규칙은 확인하지 못했다. 공식 문서는 매시 :30 생성과 :45 이후 제공를 설명한다. 단기 API는 요청·응답 일치와 필수 값 검증이 실제로 통과했다.

권장하는 결정은 **공식 설명이 없는 요청 선택도 제한된 실측 검증으로 평가할 수 있도록 근거 기준을 넓히되, 기존 정확 일치 수용 조건은 유지하는 것**이다. 이는 미검증된 정시 요청을 즉시 제품에 적용하거나 항상 30분을 보정하자는 승인이 아니다. 아래 검증이 실패하면 교정을 채택하지 않는다.

## 근거 기준 변경 후 한정된 진행안

제품 계약을 바꾸지 않는 제한 진단 자체는 기존 승인 범위에서 가능했다. 사용자는 제품 채택에 사용할 근거 기준까지 실측으로 넓히도록 승인했으며, 같은 승인을 다시 요구하지 않는다.

1. 같은 공개 격자·Preview 회원·실제 예산·일회 전송·짧은 만료·삭제 확인 조건으로 새 실측을 설계한다. 이전 실행기의 DISPATCHED 기록과 capability는 재사용하지 않는다. 현재 시각에서 충분히 과거인 정시 두 개를 명시적으로 요청하여, 응답이 그 정시와 정확히 일치하는지 또는 요청과 무관하게 30분 이전으로 이동하는지 구분한다. 이 실험 자체는 저장이나 제품 수용 조건을 변경하지 않는다.
2. 두 응답이 모두 요청과 정확히 일치하고 실제 parser와 대상 시각 필수 값 검증까지 통과하면 요청 선택 후보를 설계할 근거로 사용한다. 두 과거 표본만으로 최신 발표 선택·공개 지연·여섯 시간 ETA 끝의 지원이 입증되지는 않는다. 하나라도 실패하면 고정 오프셋·응답 시각 역적용·단기 모델 대체를 구현하지 않는다. 호출 결과가 불명확하면 자동 재시도하지 않는다.
3. 교정 후보는 `latestForecastBase`의 초단기 요청 선택과 관련 일정 테스트로 한정한다. API 주소, `parseKmaItems`의 정확 일치, grid·값·중복·필수 항목 검증, 실제 예산, 스냅샷 저장 기준은 유지한다. 요청과 응답이 일치한 발표시각으로 데이터 나이와 유효기간을 계산한다. 공식 문서와 다른 실측 의존성을 정본에 명시한다.
4. 구현 전에 정확한 선택 식·공개 지연 경계·여섯 시간 ETA 끝의 기대 결과와 검증 기준을 확정해야 READY로 표시한다. 한국시간 :45 전후·시간/날짜 경계, 초단기 예측 범위 끝, 누락 대상, 불일치 시 쓰기 0, 예산 실패, stale 표시를 검증한다. 합성 경계 검사와 실제 공급자 공개 시각의 확인을 구분한다. 독립 고정 SHA 검토와 CI를 완료한 뒤 Preview에만 적용하고, 실제 날씨·컬렉션·공유·회수 경로를 확인한다. Production은 기존의 별도 승인 경계를 유지한다.

## 유지할 대안과 영향

공식 규칙 필수 조건을 유지하면 현재 strict 거절과 오류 표시가 계속된다. 새 공식 자료가 나타나기 전까지 요청 선택을 바꾸지 않으며, 외부 문의를 해결 조건으로 요구하지 않는다. 공개 문서의 경로 예시 누락만 근거로 canonical URL을 변경하지 않는다.

사용자가 이 진행안을 승인했고 후속 정시 19:00/18:00 실측은 모두 요청·반환 및 정확 target 필수 값 PASS였다. [최소 구현 계약](2026-09-05-kma-hour-correction-plan.md)을 확정해 READY로 전환했다. 승인과 실측만으로 실제 날씨 흐름 해결·Preview GREEN을 선언하지 않는다.

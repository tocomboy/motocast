# Preview 잔여 gate와 인터뷰 결정 목록

2026-09-06. 전체 Goal은 미완료다. 최신 사용자 지시인 **현재 두 실사용 계정만 사용 가능, 계정·자료 모두 보존**을 우선한다. 이미 승인된 임시 Auth fixture 생성·정리와 제품의 실제 Kakao 신원은 구분한다. 순서 변경이나 승인된 검증 재실행을 새 승인 항목으로 만들지 않는다.

실패 시험 정리, 도구 수정·검토, 최종 자연 만료·공유 차단 연결 시험까지 완료했다. 다음은 증거·정본·운영 문서 동기화와 문서 후보 검토/CI, 남은 실제 사용자·실패 조건 인터뷰다. 이 순서로 원래 완료 기준을 축소하지 않는다.

## 미해결 결정과 입력

| 항목 | 확인한 근거·미해결 이유 | 권장안과 영향 | 의존 작업·상태 |
| --- | --- | --- | --- |
| 최초 가입 관찰에 필요한 신규 Kakao 신원 | 사용자: 두 계정 모두 실사용이며 보존. 이미 가입한 두 계정으로 최초 가입 재현 불가 | 신규 신원을 실제로 사용할 수 있을 때 소유자가 직접 로그인. 기존 계정 삭제·회수는 선택지에 넣지 않음 | 최초 가입 gate BLOCKED. 이미 받은 계정 답변을 반복 질문하지 않음 |
| 기존 라이더 재접속 경험 | 활성 membership의 무초대 재로그인 구현 확인. 직접 관찰 자료 부족 | 주소 재접속/필요시 같은 Kakao 재로그인 경험을 먼저 확인. 비밀값·인증 자료를 채팅으로 수집하지 않음 | 질문 전달 완료, 미답변. 다른 준비 작업 계속 |
| 공급자·예산 실패의 안전한 실제 관찰 조건 | active weather handler의 KMA host와 전역 quota가 고정됨. 격리 함수/가짜 실패는 active v12 실패 증거와 다름 | 전역 값 변경이나 실제 quota 고갈 없이 관찰할 수 있는 조건을 설계한다. 별도 환경 주입 결과는 별도 증거로 유지 | 독립 준비 후 인터뷰 대상. 미확정 방식에 의존하는 active 실패 시험만 보류 |
| Production 구성·승격 실행 | Preview 미완료, 기존 운영 별칭은 과거 develop 배포이며 main ref와 다름 | 모든 gate와 배포/백업/비용/영향/롤백안을 확정한 뒤 develop→main 승격 승인 요청 | 최종 승인안 준비 중. 이번 Preview 승인으로 확대하지 않음 |

이 문서는 새 권한·제품 정책·운영 변경 승인이 아니다. 실패 이력과 미실행 항목을 유지하며, 정리 실패를 별도 복구 PASS로 덮어쓰지 않는다.

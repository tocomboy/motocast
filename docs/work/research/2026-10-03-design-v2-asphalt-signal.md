# 디자인 v2 · 아스팔트 & 시그널

## 목표와 범위

운영 중인 웹·Android 화면 디자인을 새 디자인 체계로 **한 번의 출시에서 함께** 전환한다. 화면별 부분 교체는 하지 않는다.

- 포함: Figma 디자인 체계(색·글자·치수 변수, 공통 부품), 웹 PC·웹 모바일·Android의 모든 화면과 상태 재디자인, 화면 적용, 전환 출시 계획.
- 제외: 기능·데이터·서버 계약 변경. 기존 정상·오류·권한 계약과 문구의 의미는 유지한다.
- 작업 브랜치: `review-design-v2-20261003` (기반 `origin/develop` `ec9ec73`, 0.10.0). 작업 공간 `C:/Users/User/Desktop/worktrees/motocast-design-v2-20261003`.

## 확정 결정 — 2026-10-03 사용자

1. 방향은 "아스팔트 & 시그널"이다. 기존 크림·연주황 체계를 대체한다. [디자인 선행 규칙](../../rules/design-before-implementation.md)의 "기존 색상·서체 재사용"과 충돌하지만, 이번 전면 개편에서는 사용자 결정을 우선한다. v2가 정본이 되면 규칙 문서를 갱신한다.
2. 운영 중이므로 웹·Android 전체 화면을 한 번에 바꾼다.
3. 구간별 날씨는 시각 → 장소 → 기온 → 강수 막대의 타임라인으로 보여준다. 강수 단계는 기존 제품 기준(강수확률 40% 이상·강수 예보·확률 누락 = 강수 가능성)을 유지한다.
4. 숫자 전용 글꼴 Barlow Semi Condensed를 추가한다. 한글은 Noto Sans KR을 유지한다.
5. 주행 화면 색상 옵션:
   - 다크·라이트 두 가지만 제공한다. 기본값은 라이트다.
   - 선택은 기기별로 저장하고, 계정·서버에는 저장하지 않는다.
   - 주행 화면에만 적용하며, 다른 화면은 라이트를 유지한다.
6. 대비: 순검정·순백 조합(17.8:1)은 눈이 피로하고 12.5:1은 흐리다는 피드백에 따라 글자색을 `#20252A`로 정했다.
7. 바탕 밝기: 바탕 회색이 어둡다는 피드백에 따라 후보 4개(A 현재 `#E8E9E6`, B `#EEEFEC`, C `#F2F3F0`+테두리, D `#F6F6F4`+테두리)를 Figma에서 비교했다. 사용자는 **D**를 택했다. 바탕 `#F6F6F4`, 카드 `#FFFFFF`이며 카드는 1px `border/card` `#DCDEDA` 테두리로 구분한다. 목록 안 구분선도 `border/card`를 쓴다. 대비는 글자/카드 15.4:1, 글자/바탕 14.3:1, 보조 글자/카드 6.9:1이다.
